# UCS Tracker

O **UCS Tracker** é uma aplicação web desenvolvida para auxiliar estudantes no acompanhamento de disciplinas, cálculo de médias e planejamento acadêmico ao longo do semestre.

O projeto surgiu a partir da necessidade de calcular rapidamente médias, notas mínimas para aprovação e acompanhar o desempenho em diferentes disciplinas, facilitando a organização dos estudos entre amigos e colegas de curso.

## Funcionalidades

* Cadastro de disciplinas.
* Definição da quantidade de avaliações.
* Cálculo de médias aritméticas, ponderadas, harmônicas e harmônicas ponderadas.
* Configuração da nota mínima para aprovação.
* Armazenamento local dos dados no navegador.
* Interface simples, rápida e responsiva.

## Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript
* LocalStorage

## Objetivo

O objetivo do UCS Tracker é fornecer uma ferramenta prática para estudantes acompanharem seu desempenho acadêmico e simularem cenários de notas, permitindo identificar quanto precisam obter nas próximas avaliações para alcançar a aprovação.

## Aviso

Os cálculos fornecidos pela aplicação têm caráter informativo e servem apenas como auxílio aos estudantes. Recomenda-se sempre conferir os critérios de avaliação oficiais definidos pela instituição de ensino e pelos professores das disciplinas.

## Desenvolvimento

Este projeto foi desenvolvido de forma independente com o auxílio de ferramentas de Inteligência Artificial, utilizadas para apoiar o desenvolvimento, revisão de código, design da interface e implementação de funcionalidades.
